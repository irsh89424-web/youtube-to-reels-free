# Editing rules

- Free transcription uses faster-whisper CPU INT8.
- Default model `base`; `tiny` is faster, `small` may be more accurate but takes longer.
- Highlight selection scores transcript windows using speech density, hook vocabulary, punctuation and sentence-ending signals. It is not semantic AI.
- Review context, captions and crop before publishing.
- Centre crop is not face tracking.
- GitHub artifact retention is seven days.
